# 舰种图标来源

本目录保存碧蓝航线 BWIKI 舰船详情页使用的 `ShipType-*.png` 原始舰种图标。例如[杜威详情](https://wiki.biligame.com/blhx/杜威)使用 `ShipType-驱逐.png`。

- 原始 PNG 直接保存，没有重绘、裁切、换色或AI生成。
- 共15张原图，覆盖18个名称：17种当前自身舰种，以及科技奖励中的通用“风帆”。
- 标准图标52×32px；风帆50×30px。均为RGBA，透明边缘与原来的彩色底板保留，适合深色界面直接显示。
- BWIKI的风帆S、V、M文件均指向同一通用风帆原图；本工具不伪造子类差异。
- `manifest.json` 按中文舰种名提供本地路径，保留精确下载URL、文件详情页、源文件时间及校验值。
- 素材版权归游戏原权利人；本目录不将游戏美术标注为项目自有或开源授权。

维护者可在项目根目录运行 `node scripts/update-hull-icons.mjs` 更新。应用运行时读取本地素材，不访问图片外链。
