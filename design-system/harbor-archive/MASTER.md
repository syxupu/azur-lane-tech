# 港区档案 UI 规范

本次为现有纯 HTML / CSS / 原生 JavaScript 应用的界面重构。保留原有存档键、图鉴 ID、三种状态与 JSON 备份格式。

## 依据

明确使用 ui-ux-pro-max。两次 `--design-system` 查询分别返回 wellness / organic 和 gaming showcase / 3D，未匹配“长期使用的舰船练级清单”，因此未保存或套用这些推荐。以下是依据技能通用规则与当前产品需求做出的项目设计决定。`focus not obscured --domain ux` 匹配到 Web 焦点无遮挡条目；`mobile filter disclosure --domain ux` 匹配到筛选标签换行、移动优先条目。

## 视觉与内容

- 默认深海蓝工作台：背景 #0D1826、卡片 #17283B、青绿强调色 #7CE3D2。页面、卡片、控件、弹窗、选择状态及文字全部使用语义颜色变量，由主题生成器为当前模式生成；游戏头像和稀有度原色保留。
- 基础字号16px，舰名16px，普通控件14–16px，辅助文字不小于12px；手机输入与下拉16px，中文系统字体，数字使用等宽字形，全部本地资源。
- 交互输入边框使用独立control-border变量，目标对比度至少3:1；主要正文、辅助文字、强调文字与状态文字对各语义表面的对比度至少4.5:1。自定义色过亮/过暗时限定实际表面亮度并校正强调色，界面说明调整结果，保存用户输入原色。
- 标题28–32px，间距按4/8px递增，圆角8/12/16px，边框和色块提供层级；不用大幅宣传hero、3D、外部字体或装饰动画。
- 顶栏→简洁标题→紧凑进度→用户自定义科技目标→筛选与舰船清单。科技目标默认空，可添加和删除，保存在原偏好键的targets字段。状态分组在清单上方，目标加成统计与搜索结果分清楚。
- 工具操作使用统一24px线性SVG图标；舰种使用BWIKI保存的原始游戏PNG，保留相邻文字标签。船头像保留本地资源、尺寸和懒加载。

## 交互与响应式

- 快捷目标、状态按钮保留DOM节点；列表重绘后以舰船ID恢复键盘焦点，舰船被筛走后移到下一项或结果标题。
- 单舰勾选方框移除：整卡/整行用独立原生透明按钮选择，支持空格/回车、aria-pressed、已选文字和高亮。舰名链接和状态菜单位于按钮上层，独立操作；不将交互控件嵌套进按钮。全选控件保留。
- 主要控件最小44px；桌面卡片3–4列，平板2–3列，窄手机1列。目标删除按钮的点击范围与下方进度文字分开。小字不随屏幕缩小。
- 1024px以下筛选使用原生dialog；移动同一筛选表单进入对话框，关闭归还到桌面容器，避免重复ID。应用后返回触发按钮。
- 批量操作条显示选中总数；全选明确含其他页。底部留白和滚动留白随操作条高度变化，避免挡住最后一项。
- “科技总览”作为次级对话框，按受益舰种展示属性卡片，避免手机横向表格。
- 手机完成度面板保留全部舰船三种状态的数量；清单状态分组显示当前筛选范围的数量，二者用途不同。
- 标签组可自然换行；表格在小屏改为带列标题的纵向条目。
- 明确可见的键盘焦点、单个完整语句的live region反馈、语义状态文字、reduced-motion支持。

## 外观设置

- 顶栏齿轮打开原生dialog；显示模式提供浅色/深色/跟随系统。默认深海青深色，保留原有使用习惯。
- 六套预设使用配色缩略图、名称、选中边框与勾号；自定义可编辑强调色/页面背景/卡片底色。HEX与原生取色器同步，非法HEX不应用，给出相邻文字错误。
- 明暗自定义独立保存，切到预设不会抹掉自定义值。实时预览保留输入焦点和光标；系统自动变色时强制同步当前模式输入值。
- 外观使用独立localStorage键，不覆盖进度和科技目标；首屏使用已验证缓存减少配色闪烁。恢复默认仅影响外观，存储失败显示持久警告。
- 桌面预设3列，手机2列；手机颜色输入改为单列，最小44px点击区域、16px输入字号。底部操作栏固定在面板内，Esc/关闭/完成返回设置按钮。

## 验证

检查320/390/768/1024/1440px视口、浏览器缩放、焦点恢复、筛选dialog键盘操作、跨页选择、批量条遮挡、旧存档读取、导入导出和控制台错误。用户数据测试使用独立测试来源或先备份后精确恢复，不能把真实港区记录重置。
